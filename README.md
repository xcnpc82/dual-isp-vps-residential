## 原生 IP、住宅 IP、双ISP：三个词被混用得最厉害

这三层是递进关系，不是同义词。

**原生 IP** 只说明 IP 的注册地和机房物理位置对得上。洛杉矶机房的 IP，WHOIS 里国家写美国，就叫原生。但它的归属仍可能是数据中心。

**住宅 IP** 往前一步，要求 IP 的归属 ASN 是 Comcast、AT&T、中华电信这类民用宽带运营商，而不是 Linode、Vultr 这类 IDC 运营商。风控库里它长得像一个普通家庭用户。

**双ISP** 再往前一步：同一个 IP 在两家的民用 ISP 名下都有注册记录，常见组合比如美国 Comcast + Charter、香港 iCable + HGC。它的冗余意义在于，一个 ISP 的段被平台批量标记时，另一个 ISP 的段还能用。

有两件事必须说清楚，否则很容易买错。

**第一，双ISP 不等于两个 IP。** 所有套餐默认只给 1 个 IPv4，需要多 IP 要单独加购。

**第二，双ISP 是 IP 属性，9929 和 4837 是线路属性，两者互相独立。** 同一台机器可以是"双ISP 住宅 IP + 9929 回程"，也可以是"双ISP 住宅 IP + 4837 回程"，还可以是"普通机房原生 IP + 9929 回程"。市面上不少介绍把这两层混在一起讲，导致有人以为买了 9929 就自动带住宅 IP——丽萨主机恰恰把这几种组合拆开卖，价差主要就来自这两层的取舍。

两条线路的差别也很具体：

- **9929（AS9929）** 是联通 CUII 精品网，国内三网晚高峰丢包少、延迟低，代价是带宽上限基本卡在 100Mbps。
- **4837（AS4837）** 是联通 CUG-Optimized，带宽能拉到 300Mbps 甚至 1000Mbps，单价更低，晚高峰延迟波动比 9929 略大。

三网回程走联通 AS9929，移动回程走 CMIN2，电信去程各家骨干直连——这是 9929 那条线的实际走向。

## 下单前必须知道的限制

**默认只有 1 个 IPv4。** 双ISP 说的是同一个 IP 在两个 ISP 名下注册，不是给你两个 IP。多 IP 要单独加购。

**9929 带宽天花板是 100Mbps。** 这不是商家限制，是线路本身的上限。要 Gbps 级带宽只能走 4837 或纽约/芝加哥。

**IP 段会变，下单前问一句。** 9929 一期是 192 段，二期是 206 段，不同段在特定平台的风控严宽不一样。补货会换段，在工单里确认当前库存段能省掉买完才发现不可用的麻烦。

**部分 IP 段禁 ping。** 官网在 9929 产品说明里注明"应 IP 提供方要求，此产品部分 IP 段禁了 ping"，ping 不通不代表机器有问题。

**非大陆优化节点要自建中转。** 纽约、芝加哥、新加坡、台湾、英国、越南这几组官网自己标了非大陆优化；日本 IIJ 和部分住宅 VDS 同理。没有现成中转节点的话，优先洛杉矶 9929/4837。

**1G 内存装不了 Windows。** 全系 KVM，下单列表里只有 Linux 发行版。要 Windows 得提交工单让客服装，官方建议至少 2G 内存起步——68 元那档 1G 的精简版不适合。
